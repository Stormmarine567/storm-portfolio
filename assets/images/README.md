# Placeholder images

Every image here is a generated placeholder (run `npm run build:images` to regenerate).
Replace them with your real files, keeping the same name, or paste new URLs in the admin panel.

| File | Used for | Suggested size |
|---|---|---|
| hero.svg | Home hero background (Settings > Hero image URL) | 1600x900 |
| portrait.svg | About section portrait (Settings > Portrait image URL) | 600x800 |
| workspace.svg | About section second image | 1000x560 |
| shopvault.svg, datapulse.svg, nestfind.svg, connecthub.svg, vaultpay.svg, medconnect.svg, learnpath.svg | Project covers (admin > Projects > Image URL) | 1200x800 (3:2) |
| icons/*.svg | Tools & Technologies tiles (admin > Skills > Icon URL) | any square SVG/PNG |

Also add your CV as `assets/resume.pdf` — both "Download CV" and "Download Résumé" buttons point to it.
